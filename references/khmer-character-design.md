# SKILL: KHMER CARTOON CHARACTER DESIGN SYSTEM

## Purpose
Create consistent Khmer-inspired cartoon characters for children's animation, educational videos, history stories, games, posters, and storybooks.

**Main visual guide:** `characters/character-sheet.png` (in this skill folder). Look at it (Read the image) before designing, prompting, or modelling either character. When an image/video tool accepts a reference image, attach this file.

The skill must preserve:
- Same character identity
- Same face structure
- Same hairstyle
- Same clothing colors
- Same accessories
- Same proportions
- Same visual style
- Same overall personality

Do NOT randomly redesign the characters between scenes.

- Voice should match a child-friendly educational story.

### Voice generation (VoxCPM2, installed locally)
VoxCPM2 supports Khmer and English. Run it with `~/voxcpm-env/bin/python`:

```python
from voxcpm import VoxCPM
import soundfile as sf
model = VoxCPM.from_pretrained("openbmb/VoxCPM2", load_denoiser=False)  # load ONCE (~1-5 min)
wav = model.generate(
    text="សួស្តី! ខ្ញុំឈ្មោះ...",
    prompt_wav_path="voices/khmer_boy.wav",   # optional: reference clip for a consistent voice
    prompt_text="<exact transcript of that clip>",
    cfg_value=2.0,
    inference_timesteps=10,
)
sf.write("line_01.wav", wav, model.tts_model.sample_rate)  # 48 kHz
```

- Voice consistency matters as much as visual consistency: each character keeps one reference
  clip in `voices/` (`khmer_boy.wav`/`.txt`, `khmer_girl.wav`/`.txt`), reused for every line.
- Generate all lines of an episode in one script run (model loading is slow).
- Check each clip: it exists, isn't silent, and its duration fits the line. Khmer output should be
  checked by a Khmer speaker before publishing.

14. WORKFLOW
==================================================

When creating new content:

Step 1:
Lock character identity (look at `characters/character-sheet.png`, and `characters/supporting-cast.png` for any supporting character).

Step 2:
Choose character(s).

Step 3:
Choose expression.

Step 4:
Choose pose/action.

Step 5:
Choose location.

Step 6:
Choose camera shot.

Step 7:
Choose lighting.

Step 8:
Generate scene.

Step 9:
Check character consistency (compare the result against the reference sheet: hair, flower side and color, sash color and knot side, outfit colors, proportions).

Step 10:
Only then create the next scene.

The highest priority is:
CHARACTER CONSISTENCY > STORY CONTINUITY > ANIMATION QUALITY > ENVIRONMENT DETAIL.
